## 3. Data classification matrix

Classes follow kernel parity (`src/ewcp/policy/egress.py` — `BUILTIN_ALLOW`):
`sensitive` (default; any undeclared tenant is sensitive — fail-closed) and
`non_sensitive` (`demo`, `default` built-in). Classification is a per-tenant
config decision (`tenant_classes` / `EWCP_TENANT_DATA_CLASS`), **not** a
content scan.

| Data object                                              | Where it moves / lives                                                           | Class rule                                  | Enforced path                                                                                                                          |

| **ERP data**                                             | Arrives via kernel responses + tool results; persists into checkpoints/artifacts | Tenant class (ERP tenants = `sensitive`)    | Tool channel at execution; model channel when re-injected into prompts; kernel↔gateway hop stays in-boundary                           |

## 4. Mode matrix — `local_only` / `restricted` / `approved_cloud`

| Surface                    | `local_only`                                                                                                          | `restricted`                                                                                                               | `approved_cloud`                |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| Model endpoints            | loopback / private IPs / declared `local_model_endpoints`                                                             | `allowed_model_endpoints` only                                                                                             | `approved_model_endpoints` only |
| Tool surface               | builtins only: `_SAFE_BUILTIN_TOOLS` + `_FILESYSTEM_TOOLS`; `bash` iff sandbox verdict OK; web/MCP/unknown **denied** | + `allowed_tools` (name) **and** any `url`/`uri`/`endpoint` arg must land in `allowed_domains` (per-destination — this PR) | unrestricted                    |

| MCP                        | denied at tool seam (all non-builtin); no external server may be enabled anyway                                       | tool allowlist + destination allowlist; session itself is config-plane                                                     | unrestricted                    |
| Exports/permalink          | host-auth surface unchanged; permalink still public by design                                                         | same                                                                                                                       | same                            |

**Fail-closed behavior when enforcement is missing:** unprovable model
endpoint → deny the call; unprovable/unmanaged sandbox config → refuse the
run; unknown tenant → `sensitive` + `default_mode` (`local_only` out of the
box); spoofed/unknown `ewcp_egress_mode` context override → ignored, falls
back to tenant map. Auxiliary LLM calls are the documented exception: the
extension seam cannot see them, so residency for title/suggestions/
input_polish/summarization/memory rests on config discipline alone — listed
here so it is never claimed as enforced.
